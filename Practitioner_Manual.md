# Know More IQ Test: Comprehensive Practitioner Manual (Deep Edition)

## 1. Overview

The Know More IQ Test is a modern, adaptive, multi-dimensional cognitive assessment designed to measure real cognitive capability across twelve distinct dimensions. It replaces legacy IQ models with a dynamic, process-aware system that evaluates reasoning, adaptability, pattern extraction, abstraction, and meta-cognitive control.

This manual provides practitioners with the full architecture, administration procedures, scoring rules, adaptive branching logic, integrity safeguards, and scenario walkthroughs necessary to administer and interpret the test.

## 2. Philosophy & Design Principles

### 2.1 Core Premise
Traditional IQ tests measure static problem-solving under artificial constraints. The Know More IQ Test measures how a mind moves, not just what it knows.

### 2.2 Guiding Principles
- **Agency-Safe:** The test never pressures, manipulates, or traps the participant.
- **Adaptive Depth:** Tasks scale in complexity based on demonstrated capability.
- **Dimension-Pure:** Each task isolates a single cognitive dimension.
- **Process-First:** The way a participant solves a task is as important as the result.
- **Emergent-State Detection:** The system tracks transitions, not just outcomes.

## 3. The Twelve Cognitive Dimensions

Each dimension is measured through a structured progression of tasks (Tier 1 → Tier 2 → Tier 3). Tier 3 includes multiple depth layers.

| Dimension | What It Measures |
| :--- | :--- |
| **Pattern Extraction** | Ability to detect structure in noise, identify invariants, and generalize. |
| **Structural Mapping** | Skill in translating one system's structure into another. |
| **Temporal Reasoning** | Understanding sequences, causality, and dynamic evolution. |
| **Spatial Cognition** | Manipulating shapes, rotations, and geometric transformations. |
| **Abstraction** | Moving from concrete examples to general principles. |
| **Compression** | Reducing complexity while preserving meaning. |
| **Divergent Generation** | Producing multiple valid solutions or interpretations. |
| **Convergent Resolution** | Selecting the single most coherent solution. |
| **Meta-Cognitive Control** | Monitoring one's own reasoning, detecting errors, and self-correcting. |
| **Constraint Navigation** | Working within rules, limits, and tradeoffs. |
| **Novelty Response** | Handling unfamiliar, ambiguous, or unstable situations. |
| **Cognitive Endurance** | Sustaining clarity, precision, and adaptability over time. |

## 4. Test Structure

### 4.1 Session Flow
1. **Orientation (2–3 minutes):** Standardized introduction.
2. **Baseline Calibration:** Tier 1 tasks across all dimensions.
3. **Adaptive Branching:** Tier 2 tasks for dimensions showing strength.
4. **Deep Probing:** Tier 3 multi-layer tasks.
5. **Cooldown Reflection:** Optional debrief.

### 4.2 Timing & Environment
- **Total session:** 35–55 minutes.
- **No forced time limits:** The system tracks natural pacing.
- **Environment:** Quiet, stable environment with no external aids. The practitioner remains neutral and non-directive.

## 5. Administration Protocol

### 5.1 Practitioner Role
- Provide instructions exactly as written.
- Do not hint, guide, or evaluate aloud.
- Maintain a calm, neutral presence.
- Protect participant agency at all times.

### 5.2 Task Delivery Rules
- Present one task at a time.
- Allow participant to verbalize or remain silent.
- Record both answers and process notes.
- Move to next task only when participant signals completion.

## 6. Adaptive Branching Logic

### 6.1 Tier Advancement
A participant advances to the next tier when they demonstrate consistent competence in the current tier and their process shows stability and clarity.

### 6.2 Depth Scaling (Tier 3)
Tier 3 tasks contain Depth Levels 1–5:
- **Level 1:** Simple extension of Tier 2.
- **Level 2:** Multi-step reasoning.
- **Level 3:** Cross-dimensional interference.
- **Level 4:** Novel structure introduction.
- **Level 5:** Emergent-state challenge.

### 6.3 Failure Conditions
A participant does not advance when they show confusion without recovery, rely on guessing, or lose structural orientation.

## 7. Scoring System

### 7.1 Multi-Layer Scoring
Each dimension receives four sub-scores:
- **Outcome Score:** (0–10)
- **Process Score:** (0–10)
- **Depth Score:** (0–5)
- **Stability Score:** (0–5)

### 7.2 Composite Index & Interpretation Bands
The final Know More IQ score is a weighted integration of all dimension scores, stability curves, and depth achievements.

| Score Band | Interpretation |
| :--- | :--- |
| **0–40** | Foundational |
| **41–70** | Developing |
| **71–100** | Advanced |
| **101–130** | High Capability |
| **131+** | Exceptional Cognitive Range |

## 8. Integrity & Bias Safeguards

- **Practitioner Neutrality:** No feedback, praise, or discouragement.
- **Anti-Bias Architecture:** No cultural knowledge required, no language-dependent tasks, no socioeconomic assumptions.
- **Agency Protection:** Participants may pause or stop at any time.

## 9. Scenario Walkthroughs

- **High Performer:** Rapid Tier 1 clearance, strong structural mapping, deep Tier 3 penetration, high stability across dimensions.
- **Uneven Profile:** Strong spatial cognition, weak temporal reasoning. Adaptive branching isolates strengths and weaknesses cleanly.
- **Novelty-Sensitive:** Strong performance until Tier 3 Level 4, sudden destabilization, recovery tracked as meta-cognitive indicator.

## 10. Maintenance & Updates

- **Task Bank Rotation:** Replace 10–15% of tasks quarterly to maintain dimension purity.
- **Calibration Checks:** Validate scoring consistency monthly and run internal benchmark tests.
- **Practitioner Review:** Annual re-certification recommended.
