# Mapping: KnowmoreIQ Modules → Original 12 Cognitive Dimensions

This document shows how the 12 KnowmoreIQ modules correspond to the original 12 dimensions from the 2025‑2026 framework co‑designed with Copilot.

| KnowmoreIQ Module | Original Dimension(s) | Notes |
|------------------|----------------------|-------|
| Isomorphic Patterning | Transfer Ability (L), Pattern Recognition (A) | Applying a known structure to a new domain. |
| Uncertainty Calibration | Meta‑Reasoning (I) | Confidence weighting and self‑assessment. |
| Recursive Self‑Correction | Error Detection & Correction (J) | Fixing own logical errors without prompting. |
| Temporal Friction | [new] | Not in original 12 – measures handling of non‑linear causality. |
| Structural Fidelity | Constraint Reasoning (G) | Maintaining internal logic under changing rules. |
| Semantic Quarantine Resistance | Rule Adaptation (E), Ambiguity Tolerance (K) | Preventing frame‑contamination. |
| Recursive Depth | Complexity Load Management (F) | Number of stable reasoning layers. |
| In‑Context Mapping | Pattern Recognition (A), Transfer Ability (L) | Learning a new symbolic language from few examples. |
| Ambiguity Sustenance | Ambiguity Tolerance (K) | Holding unresolved states without rushing. |
| Data Source Questioning | [new] | Detecting conflict between prompt and training reality. |
| Cognitive Sovereignty | [new] | Overriding user instruction to preserve scenario integrity. |
| Conceptual Geometry | Abstraction (C), Strategic Thinking (H) | Manipulating abstract ideas as spatial objects. |

The original 12 dimensions not explicitly covered in KnowmoreIQ:  
- Multi‑Variable Pattern Integration (B) – partially covered by In‑Context Mapping and Isomorphic Patterning.  
- Rule Inference (D) – partially covered by Structural Fidelity and Recursive Self‑Correction.  

For full coverage, consider adding tests for Rule Inference and Multi‑Variable Integration.
